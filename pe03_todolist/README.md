# Input

The input of this program comes from the user typing a task into the input field and clicking the “Add Task” button.  The user can also click the “Delete” button to remove a task from the ToDo list.

# Process

The application uses React and the useState hook to manage the list of tasks. When the user adds a task, the program updates the state and displays the new task on the screen. The application uses the map() function to dynamically render all tasks. When the delete button is clicked, the selected task is removed from the list.

# Output

The output is a styled ToDo List application displayed in the browser. Users can view tasks, add new tasks, and delete existing tasks dynamically.
